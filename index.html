Show HN: Impossible Machines: declaratively program the physical world

2026-10-22 @ 23:54:28Points: 8Comments: 0

Sharing a thought experiment I put together. The premise: what might declarative programming feel like for the physical world?

We’re already familiar with this paradigm in software land (eg SQL etc where we declare what we want and the execution engine figures out how).

I didn’t have access to an actuator so I mocked up the concept in software. The way it works is you demonstrate the effect and the system figures out how to achieve it. So say you want to ring a bell and you have a crank. The system will find a way to connect the two. If you add obstacles it figures out how to work around them (runs a constraint solver runs behind the scenes).

I think what’s interesting about this is being able to think about the problem at a higher level of abstraction, with the system figuring out a way to achieve the intended effect.

Anyways, curious to read reactions, feedback, and interesting ideas on how to extend this!

Show HN: OnKey – I'm a bad singer, so I built an app to show where I'm off-key

2026-10-22 @ 14:04:44Points: 162Comments: 69

I was pretty terrible at singing, now I’d say I’m bad but not terrible. This is because I’ve been using a singing app (won’t name it here) that scores me on my pitch and timing throughout the song so that I can improve.

Lately however, the app I’ve been using has flooded their song list with songs that aren’t originals. I didn’t like this at all as for me, it’s easier to try to improve when you’re singing along to the original.

So, I asked an agent (Claude Code) if it could write some code to listen to Spotify and also listen to me and see if it could detect both pitches and score me. It impressed me by writing some Python and showing me my pitch in the terminal!

It couldn’t go all the way though and detect the singer’s pitch in real time.

So I found the next best setup and built OnKey, a Mac app that needs to listen to the song once (it doesn’t save it) and then when it’s learnt the song (takes a couple of minutes), you can sing along to the pitch track that it’s learnt. OnKey is free to use and open source under the MIT license.

It can listen to Spotify, Apple Music, and YouTube playing in your browser with the right permissions.

During the build I found that someone had done something similar in Nightingale, but this requires a library of songs exported to disk and who has this in 2026 (maybe some of you ;) - but we need to help the normies too).

You can check out a demo video on the site of me singing (warning given) here: https://singonkey.app

The app sends out to find the song info (short Shazam fingerprint, and looks up song details), lyrics (from LRCLIB), and checks for updates.

The app never sends the music (it doesn’t save this to disk) and your voice. Everything you’d expect to stay private does.

It’s still weak in a few places:

- when the song’s backing is noisy it’s hard to pick the pitch track out

- sometimes it gets a note an octave off

- it’s limited to Apple Silicon Macs, M1 or later, and only macOS 14.2 up because extra drivers aren’t required past this point

- the scoring is built for beginners like me so it’s fairly easy on you

Would love for people to try it out and let me know what works and what doesn’t for them!
